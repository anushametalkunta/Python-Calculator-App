# Python Calculator App

A modern desktop calculator built with Python, featuring standard calculations, scientific functions, graph plotting, programming tools, and unit conversions.

## Features

- **Standard Calculator** — Perform everyday arithmetic calculations.
- **Scientific Calculator** — Work with advanced mathematical functions.
- **Graph Plotting** — Plot multiple mathematical expressions.
- **Programming Tools** — Access programming-related calculator features.
- **Unit Conversion** — Convert between supported units.
- **Modern Interface** — Use a sidebar-based graphical interface.

## Technologies Used

- Python
- Tkinter / Python GUI components
- Matplotlib (if used by the graphing feature)

## How to Run

1. Install Python on your computer.
2. Download or clone this repository.
3. Open the project folder in VS Code.
4. Install any dependencies listed in the project's requirements file, if provided.
5. Run:

   `python main.py`

## Project Structure

- `main.py` — Application entry point.
- `calculator/` — Calculator interface and feature modules.
- `tests/` — Automated tests.
